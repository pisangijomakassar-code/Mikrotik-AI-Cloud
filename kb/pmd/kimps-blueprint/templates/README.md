# Template Kerja KIMPS

Delapan template siap pakai. Salin berkasnya, ganti nama sesuai konvensi penamaan di
[04 §2](../04-matriks-artefak.md#2-aturan-pengarsipan), lalu isi.

| Kode | Template | Dipakai pada | Pemilik |
|------|----------|--------------|---------|
| TPL-01 | [Project Charter](./TPL-01-project-charter.md) | F1 | PM |
| TPL-02 | [WBS & Jadwal](./TPL-02-wbs-dan-jadwal.md) | F2 | PM |
| TPL-03 | [Risk Register](./TPL-03-risk-register.md) | F1–F4 | PM |
| TPL-04 | [Issue Log](./TPL-04-issue-log.md) | F3–F4 | PM |
| TPL-05 | [Change Request](./TPL-05-change-request.md) | F3 | PM |
| TPL-06 | [Status Report](./TPL-06-status-report.md) | F3 | PM |
| TPL-07 | [Gate Review Checklist](./TPL-07-gate-review-checklist.md) | G0–G4 | PMD |
| TPL-08 | [Project Closure](./TPL-08-project-closure.md) | F4 | PM |

**Petunjuk umum**
- Teks dalam `[kurung siku]` adalah tempat isian.
- Baris yang diawali `>` adalah petunjuk pengisian — hapus sebelum dokumen difinalkan.
- Bagian bertanda *(Tier 1 & 2 saja)* boleh dihapus untuk proyek Tier 3.
